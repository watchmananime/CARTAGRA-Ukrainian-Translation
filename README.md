# 🇺🇦 Український переклад CARTAGRA

#Український фанатський переклад **CARTAGRA — カルタグラ ～ツキ狂イノ病～**.

## 📥 Завантаження

Актуальна версія перекладу доступна у [Releases](../../releases).

**Поточна версія:** 1.0.1

**Підтримувана версія гри:** Steam build 24214864

## 🛠 Встановлення

1. Завантажте останню версію патчу з [Releases](../../releases).
2. Закрийте гру.
3. Відкрийте папку CARTAGRA через Steam:
   **Властивості → Встановлені файли → Огляд**.
4. Скопіюйте вміст патчу до кореневої папки гри.
5. Погодьтеся на заміну файлів.
6. Запустіть гру.
7. У налаштуваннях мови виберіть **Українська**.
